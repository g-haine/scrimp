assemble_rhs(source_only=False, explicit_only=False)

Assemble the GetFEM RHS into the owned PETSc entries.

GetFEM’s model.rhs() mixes two DIFFERENT signs: * generic nonlinear weak terms N(z): rhs = -N(z); * add_source_term_brick prescribed forcing S(t): rhs = +S(t).

For raw GetFEM rhs_total=-P*N(z)+S(t), a generic RHS scale alpha=1/P alone incorrectly scales the source S/P. The tested GetFEM MPI-2 build treats generic terms and source bricks differently. Opt-in SCRIMP_GETFEM_SOURCE_RHS_MODE=raw inserts unscaled source-only RHS and reconstructs the direct residual as -alpha*rhs_total + (1+alpha)*rhs_source = N(z)+S(t). match_generic (default) preserves historical uniform scaling. This flag only affects source bricks’ contribution to the direct nonlinear residual, not the physical equations or LU. See sandbox/check_mcss_source_sign.py.

audit_interface_brick_plan(interface, subdomains, mesh_id=0)

Compute a read-only plan for all declared interface bricks.

Each form is assigned to the subdomain owning its tested variable(s). In cross-domain feedback, the receiving test variable fixes the side; the source variable does not. This method does not allocate regions, alter FEM DOFs, or reassemble GetFEM. In particular it does not qualify physical port signs.

audit_interface_ownership(interface, subdomains, mesh_id=0)

Audit an interface against this DPHS’s declared ports and bricks.

The public GetFEM interface region is not modified. The domain verifies real two-sided geometry; the ownership audit then uses only explicit bulk-variable anchors in actual registered weak forms. It never silently reorients FEMs or bricks and must not be interpreted as a physical/model/DAE qualification.

Call after defining the ports and bricks (including controls). Raises InterfaceOwnershipError for missing/conflicting owners, and InterfaceTopologyError for unsupported interface geometry.

init_step()

Establish a DAE-consistent physical initial state.

The v1.3.0 default candidate algebraic projects only algebraic variables while preserving prescribed differential initial coefficients. It is linear-only; unsupported or inconsistent initial data raise explicit errors. Historical pseudo remains available by explicit request; it integrates a tiny pseudo-time PETSc TS and can move the differential coefficients. The alternative historical bdf also uses a short time integration, optionally from a negative initial time with init_step_bdf_order=2 and init_step_from_negative_time=True. PETSc BDF2 bootstraps its history internally with a half-step (PETSc 3.21).

init_step_ts_type=algebraic directly projects only algebraic variables with a distributed PETSc LSQR solve, and performs no pseudo-time integration. Explicit historical relaxation options remain available. Changing the default is subject to an independent native and migration release gate; the main physical TS remains unchanged.

See docs/V130_DAE_ALGEBRAIC_INITIALIZER_DESIGN.md.

The numerical quadrature follows each Port’s declared get_power_sampling() convention: ‘cn_step’ integrates original step powers P[k>=1] as sum(dt[k]*P[k]), never reusing instantaneous P[0]; ‘instantaneous’ integrates actual nodal P(t[k],z[k]) with a trapezoidal approximation. An unknown convention fails explicitly, preventing a silent wrong plot.

CN is already native-qualified for the tested mixed-boundary wave; exact BDF/ARKIMEX stage quadrature is NOT claimed without the underlying PETSc internal-stage data. Port signs are the original raw flow-effort orientation. If HamTot is provided, the plotted Balance retains the historic sign convention; its constancy is model-dependent.

Set a prescribed open-loop input or an implicit feedback law.

State-independent GWFL expressions use an RHS-only GetFEM source. A bare signed model variable (e.g. Y_w or -Y_T) is a provably linear feedback: GetFEM assembles its constant bilinear coupling directly into the stiffness matrix. A finite numeric scalar times a single model variable (e.g. -0.5*Y) is likewise certified linear. Other state-dependent expressions, or unknown macros, use a nonlinear variational brick so Newton computes their full derivative, not merely the residual.

compute(solution: dict, gf_model: getfem.Model, domain: Domain, *, sampling: str = 'instantaneous')

Compute raw signed flow/effort powers for an algebraic port.

Sampling is explicit rather than hardcoding Crank–Nicolson for every PETSc time integrator:

instantaneous: at every accepted (t[k], z[k]), suitable as nodal samples independent of the time scheme. Trapezoidal integration of these samples is approximate and not a claim of BDF/ARKIMEX stage quadrature or a power identity.

cn_step: at (t[0], z[0]) for k=0; for k>=1, evaluate at (t[k], 0.5*(z[k-1]+z[k])), preserving the already-native- qualified SCRIMP CN convention exactly. In particular, time-dependent GetFEM expressions are evaluated at t[k] as they were historically, not at the physical midpoint time.

Parameters:

  • solution – Accepted time/FE-state history, containing matching t and z sequences.

  • gf_model – Original GetFEM model (collective MPI assembly).

  • domain – SCRIMP integration domain.

  • sampling – instantaneous (default) or cn_step.

The returned get_power() array preserves the original port algebraic orientation. get_power_sampling() identifies the numerical meaning of each stored value.
