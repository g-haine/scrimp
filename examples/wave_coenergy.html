The wave equation — 2C: co-energy and localized damping

  • file: examples/wave_coenergy.py

  • authors: Giuseppe Ferraro, Ghislain Haine

  • date: 22 nov. 2022

  • brief: wave equations in co-energy formulation, two sub-domains

examples.wave_coenergy.main()
examples.wave_coenergy.measure_coenergy(system)

Audit actual CN midpoint FE work, damping and boundary feedback.

Here the signed algebraic boundary power U*Y is a LOSS: because the coenergy Grad-Grad coupling imposes Y=-p (weakly), the original FE balance is dH/dt=-integral(U*Y)-D_r. The passive law is U=+kY. This is not the mixed-boundary 2A/2B sign convention.

The substituted resistive port has no independent flow unknown and Port.get_power() correctly cannot report its dissipative power. We assemble its true mixed FE dissipation in two mathematically equivalent ways: D_r=integral e_r**2/nu = -integral p*e_r. The pointwise nu*p**2 is ONLY a diagnostic because e_r is DG1 and nu*p is not generally in the same FE space.

examples.wave_coenergy.wave_coenergy_eq(*, mesh_size=0.2, final_time=0.08, time_step=0.008, factor_solver='mumps')

Solve the anisotropic 2D wave in genuine co-energy variables.

q=e_q (stress), p=e_p (velocity); Tinv=T**(-1), rho as in 2A/2B. Damping acts only on the inner disk, feedback only on the outer rim. The short fixed CN scenario is for native acceptance, NOT convergence.

Why this third tutorial?

Tutorial The wave equation — 2A: conservative anisotropic membrane introduces the anisotropic 2D membrane and mixed boundary ports (2A), then a separate resistive flow/effort pair (2B). This tutorial introduces a genuinely different construction: the co-energy states themselves, a concentric two-region domain, inner damping and an outer boundary feedback. It does not replace 2A or 2B or imply identical meshes.

The actual, executable code is examples/wave_coenergy.py. Fragments below are included from that file, rather than copied into the documentation. The short default example (h=0.2, dt=0.008, tf=0.08) is a qualified native MUMPS MPI1/2 acceptance pilot, not a resolved wave-propagation demonstration or a convergence study.

The true material inverse

The physical tension and density retain the definitions of 2A/2B:

\[\begin{split}T(x,y)=\begin{bmatrix}5+x&xy\\xy&2+y\end{bmatrix}, \qquad \rho(x)=3-x.\end{split}\]

However, the co-energy formulation needs the actual compliance, not the same numeric tensor renamed Tinv:

\[\begin{split}T^{-1}(x,y)=\frac{1}{(5+x)(2+y)-(xy)^2} \begin{bmatrix}2+y&-xy\\-xy&5+x\end{bmatrix}.\end{split}\]

On the unit disk the determinant is strictly positive. The GetFEM GWFL parameter Tinv below encodes this inverse; q.Tinv.q is a tensor contraction, not a Python transpose.

The co-energy unknowns are now stress q=T grad(w) and velocity p=dw/dt. The conjugate co-states have been substituted, so they do not introduce extra FE unknowns. The mechanical energy is

\[\mathcal H(q,p)=\frac12\int_\Omega \left(q\cdot T^{-1}q+\rho p^2\right)\,\mathrm dx.\]

Two regions and substituted ports

The geometry is a unit disk split into the inner disk Omega_1 (radius 0.6, region 1) and an annulus Omega_2 (region 2). Region 10 is their interface; region 20 is the external boundary. The damping port is present only on region 1 and the boundary port only on region 20.

    # Set the domain (using the built-in geometry `Concentric`)
    # Labels: Disk = 1, Annulus = 2, Interface = 10, Boundary = 20
    omega = S.Domain(
        "Concentric", {"R": 1.0, "r": 0.6, "h": mesh_size},
        mesh_output_dir=wave.get_output_path("mesh",create=True),
    )
    
    # And add it to the dphs
    wave.set_domain(omega)


    ## Define the variables
    states = [
        S.State("q", "Stress", "vector-field"),
        S.State("p", "Velocity", "scalar-field"),
    ]
    # Use of the `substituted=True` keyword to get the co-energy formulation
    costates = [
        S.CoState("e_q", "Stress", states[0], substituted=True),
        S.CoState("e_p", "Velocity", states[1], substituted=True),
    ]
    
    # Add them to the dphs
    for state in states:
        wave.add_state(state)
    for costate in costates:
        wave.add_costate(costate)
    

    # Define the dissipative port, only on the subdomain labelled 1 = the internal disk
    ports = [
        S.Port("Damping", "e_r", "e_r", "scalar-field", substituted=True, region=1),
    ]
    
    # Add it to the dphs
    for port in ports:
        wave.add_port(port)
    
    # Define the control port
    control_ports = [
        S.Control_Port(
            "Boundary control",
            "U",
            "Normal force",
            "Y",
            "Velocity trace",
            "scalar-field",
            region=20,
        ),
    ]

    # Add it to the dphs
    for ctrl_port in control_ports:
        wave.add_control_port(ctrl_port)
    
    # Define the Finite Elements Method of each port
    FEMs = [
        S.FEM(states[0].get_name(), 1, "DG"),
        S.FEM(states[1].get_name(), 2, "CG"),
        S.FEM(ports[0].get_name(), 1, "DG"),
        S.FEM(control_ports[0].get_name(), 1, "DG"),
    ]
    
    # Add them to the dphs
    for FEM in FEMs:
        wave.add_FEM(FEM)

In the internal disk, the resistive port is substituted: nu^{-1} e_r = -p in its finite-element weak form. Unlike a non-substituted port, it has no independent GetFEM flow variable. Consequently its power cannot be obtained through Port.get_power(). The native audit instead evaluates the original FE functions by independent GetFEM quadrature.

The legacy coefficient nu=10(0.36-r^2) vanished at the interface even though a brick integrates 1/nu. Here we deliberately use nu=0.2+10(0.36-r^2) on region 1 only. This is a strictly positive, bounded invertible coefficient on the disk and still has exactly zero damping on the outer annulus by region restriction. It is a documented change to the legacy scenario, not a numerical regularization hidden in SCRIMP.

    # Define physical parameters: care must be taken, 
    # in the co-energy formulation, some parameters are
    # inverted in comparison to the classical formulation
    parameters = [
        S.Parameter(
            "Tinv",
            "Anisotropic compliance T inverse",
            "tensor-field",
            TINV,
            "q",
        ),
        S.Parameter("rho", "Mass density", "scalar-field", "3-x", "p"),
        S.Parameter(

        ),
    ]

    # Add them to the dphs
    for parameter in parameters:
        wave.add_parameter(parameter)

The co-energy balance and feedback sign

The semidiscrete system is

\[T^{-1}\dot q=\nabla p,\qquad \rho\dot p=\operatorname{div}q+e_r \quad (e_r\text{ acts only on }\Omega_1),\]

with the signed Grad–Grad boundary observation Y=-p (in the boundary FE weak sense). The trace is not the Y=p used in an alternative boundary-port orientation. The algebraic signed port power reported by SCRIMP is P_b=integral UY, and the original co-energy Dirac bricks give

\[\frac{\mathrm d\mathcal H}{\mathrm dt} =-\int_{\partial\Omega} UY\,\mathrm ds -\int_{\Omega_1}\frac{e_r^2}{\nu}\,\mathrm dx.\]

Consequently the passive control is `U=+0.5Y`: P_b=+0.5*integral Y^2 >= 0, and this port power is subtracted from the Hamiltonian. A previous trial mistakenly used U=-0.5Y: the unqualified real MUMPS MPI1/2 archive v130-wave2d-coenergy-e1c5bc50-bRo68Qaf.zip proved that law injected energy. Its measured identity was H-H0+Li-Lb=0 to 1e-15, with the entire rejected energy defect equal to twice the signed boundary work. This is a physical sign correction, not an adjustment to energy tolerances or an arbitrary renaming of power.

For the two dissipative mechanisms, define

\[D_i=\int_{\Omega_1}\frac{e_r^2}{\nu}\,\mathrm dx =-\int_{\Omega_1}p e_r\,\mathrm dx\ge0, \qquad D_b=\int_{\partial\Omega} UY\,\mathrm ds =0.5\int_{\partial\Omega}Y^2\,\mathrm ds\ge0.\]

The equality for D_i holds in the FE weak projection. The pointwise integral integral nu*p^2 need not agree exactly, because e_r is DG1, and nu*p generally is not. We record it as a diagnostic, not a false exactness gate.

There is no independent boundary drive in this scenario; therefore the physical balance to validate is

\[\boxed{\mathcal H(t)-\mathcal H(0)+ \int_0^t (D_i(s)+D_b(s))\,\mathrm ds=0.}\]
    # Define the pHs via `Brick` == non-zero block matrices == variational terms
    # Since we use co-energy formulation, constitutive relations are already taken into
    # account in the mass matrices M_q and M_p
    bricks = [
        ## Define the Dirac structure
        # Define the mass matrices from the left-hand side: the `flow` part of the Dirac structure
        S.Brick("M_q", "q.Tinv.Test_q", [1, 2], dt=True, position="flow"),
        S.Brick("M_p", "p*rho*Test_p", [1, 2], dt=True, position="flow"),
        S.Brick("M_r", "e_r/nu*Test_e_r", [1], position="flow"),
        S.Brick("M_Y", "Y*Test_Y", [20], position="flow"),
        # Define the matrices from the right-hand side: the `effort` part of the Dirac structure
        S.Brick("D", "Grad(p).Test_q", [1, 2], position="effort"),
        S.Brick("-D^T", "-q.Grad(Test_p)", [1, 2], position="effort"),
        S.Brick("I_r", "e_r*Test_p", [1], position="effort"),
        S.Brick("B", "U*Test_p", [20], position="effort"),
        S.Brick("-I_r^T", "-p*Test_e_r", [1], position="effort"),
        S.Brick("-B^T", "-p*Test_Y", [20], position="effort"),

A physically visible initial pulse

Two smooth initial velocity bumps excite the inner damping and outer feedback. The initial stress is zero. The time integrator is fixed Crank–Nicolson, ten accepted steps, with algebraic DAE initialization and default MUMPS LU. The short time interval proves the simulation and output pipeline works, but does not by itself establish long-time spatial quality.

    ## Initialize the problem
    # The controls expression
    # The Grad-Grad boundary output has Y=-p (weak trace):
    # its signed port power is U*Y and dH/dt=-U*Y-D_internal.
    # Thus U=+kY is passive: U*Y=+k*Y**2 and dH/dt<=0.
    # The previous U=-kY *injected* energy, as proved by native CN
    # H+L_internal-L_boundary=0 (e1c5bc50, MPI1/MPI2).
    expressions = [f"{FEEDBACK_GAIN}*Y"]
    
    # Add each expression to its control_port
    for control_port, expression in zip(control_ports, expressions):
        # Set the control functions (automatic construction of bricks such that -M_u u + f(t) = 0)
        wave.set_control(control_port.get_name(), expression)

    # Set the initial data
    wave.set_initial_value("q", "[0., 0.]")
    # Smooth two-part velocity pulse excites both internal damping and the
    # exterior feedback already at t=0, without prescribing a boundary trace.
    wave.set_initial_value(
        "p",
        "exp(-10*(x*x+y*y))+0.4*exp(-15*((x-0.8)*(x-0.8)+y*y))",
    )


    ## Solve in time
    # Define the time scheme ("cn" is Crank-Nicolson)
    options = {}
    if factor_solver is not None:
        options["pc_factor_mat_solver_type"] = factor_solver
    wave.set_time_scheme(
        init_step_ts_type="algebraic", init_step=True,
        ts_type="cn", ts_adapt_type="none",
        ts_exact_final_time="matchstep",
        ksp_type="gmres", pc_type="lu",
        t_0=0., t_f=final_time,
        dt=time_step, dt_save=time_step,
        **options,
    )

    # Solve
    wave.solve()


    ## Post-processing
    ## Set Hamiltonian's name
    wave.hamiltonian.set_name("Mechanical energy")
    # Define each Hamiltonian Term
    terms = [
        S.Term("Potential energy", "0.5*q.Tinv.q", [1, 2]),
        S.Term("Kinetic energy", "0.5*p*p*rho", [1, 2]),
    ]
    # Add them to the Hamiltonian
    for term in terms:
        wave.hamiltonian.add_term(term)

    return wave

Native outputs and visualizations

The pilot below records the original full FE state history in NPZ, true GetFEM Hamiltonian and power histories, detailed JSON physical gates, two independent quadratures of inner resistance, and GetFEM/ParaView time series q, p, e_r (one PVD and eleven VTU per field and MPI case). It checks strict DAE, CN work/loss balance at every step, nontrivial passive feedback and damping, MPI replica/parity, and genuine nonempty VTK fields.
